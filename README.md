## Tujuan Repositori

Repository ini berisi hasil praktikum Matematika Diskrit Modul 2. Isinya program Python untuk relasi dan fungsi, konversi sistem bilangan (biner, oktal, hexadecimal), pengecekan bilangan prima, perhitungan FPB dan KPK, serta analisis sekumpulan bilangan.

Repository ini dibuat untuk memenuhi tugas praktikum mata kuliah **Matematika Diskrit (Modul 2)**. Tujuannya adalah:

1. **Memahami teori lewat program:** Menerapkan konsep relasi, fungsi, sistem bilangan, dan teori bilangan ke dalam kode Python.
2. **Menyusun algoritma:** Melatih cara berpikir algoritmik, mulai dari memahami masalah, membuat *pseudocode*, sampai menjadi program yang terstruktur dengan fungsi.
3. **Menganalisis efisiensi:** Mengonversi bilangan antar basis dengan pembagian berulang, membandingkan pengecekan prima biasa dengan batas akar n, dan menghitung FPB dengan algoritma Euclidean.
4. **Dokumentasi:** Menyimpan hasil studi kasus dan pengujian program.
